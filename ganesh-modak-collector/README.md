# Ganesh Ji – Modak Collector 🛕✨

A devotional, culturally rich 2D browser game built with pure vanilla HTML5, CSS3, and JavaScript.

![Ganesh Ji Modak Collector](assets/top_hud_strip.jpg)

## 🌸 Divine Features

- **Devotional Temple Atmosphere**: Beautiful temple courtyard architecture with floating diyas, hanging bells, marigold garlands, and Rangoli.
- **5 Sacred Environments**:
  1. *Day – Temple Courtyard*
  2. *Evening – Riverside*
  3. *Night – Festival Lights*
  4. *Monsoon – Rainy Temple*
  5. *Spring – Blossom Garden*
- **Sacred Collectibles**:
  - High-value Modaks with golden spires
  - Motichoor Ladoos (+5 score)
  - Divine Pink Lotus Flower (activates global sacred sweet attraction power)
- **Obstacles**:
  - Terracotta Matkis (Clay Pots) to dodge
- **Lord Ganesh Ji**:
  - Authentic devotional character art with progressive aura and rotating sacred floor Yantra mandala
  - Fluid keyboard and on-screen translucent frosted-glass touch controls (◀ Left, ▶ Right, ▲ Action)
- **Authentic UI**:
  - 5-card top-left HUD cluster: `SCORE`, `MODAK`, `LADOO`, `POWER`, `LIVES`
  - Divine Attraction timer capsule with lotus glow and countdown progress bar
  - Ornate guidance tip plaque
  - Bottom journey progression track with thumbnails and active realm highlights
  - Sanskrit devotional salutation: *॥ श्री गणेशाय नमः ॥*

## 🎮 Controls

- **Desktop**:
  - Left / Right Arrow or `A` / `D` to move Lord Ganesh Ji
  - `Space` / `Up Arrow` for Action
  - `P` or Pause Button to pause / resume
- **Mobile / Tablet**:
  - On-screen touch buttons: `◀` (Left), `▶` (Right), and `▲` (Action)

## 🚀 How to Run

Simply open `index.html` in any modern web browser, or serve it via a local HTTP server:

```bash
# Python 3
python -m http.server 5500

# Node.js
npx serve .
```

Visit `http://localhost:5500` in your browser.
